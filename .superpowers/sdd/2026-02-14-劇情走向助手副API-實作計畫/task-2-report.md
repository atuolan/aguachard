## 实现说明

- 增加可折叠的“API 设置”区域，默认收起，插入在提示词设置区域之前。
- 增加“使用主 API”与全部已保存副 API 方案的下拉选择。
- 下拉切换会更新 `activeId`、写回脚本变量，并把选中方案加载到编辑表单；切换不会丢失当前表单之外的数据。
- “新增方案”生成新的方案 ID、清空编辑表单并使用 `openai` 作为 `source` 默认值，不立即改变当前 active 方案。
- “保存方案”在表单有 ID 时覆盖对应方案，没有 ID 时创建方案；保存前检查方案名称、API Base
  URL、Key 和模型，缺失字段在面板中显示，不发起网络请求。
- 保存成功后方案成为当前副 API，状态文案只显示方案名称，不显示 Key。
- “删除方案”只删除当前编辑方案；删除 active 方案时清空
  `activeId`、加载空表单并回到主 API；其他方案及脚本变量中的其他字段保持不变。
- API Key 使用密码输入框，并提供显示/隐藏切换；明文 Key 不渲染到普通文本节点。
- 增加成功、空配置、重复/无效删除等状态，以及字段校验提示。
- 增加导出安全提示，明确说明 Key 保存在脚本 `data` 中，导出或分享含数据的脚本可能暴露 Key。
- API 区使用现有面板按钮、颜色 token、窄屏宽度和滚动容器风格；API 区自身设置最大高度与滚动，展开时不突破面板最大高度。
- 未实现主 API 读取、模型列表、测试连接和正式生成接入，符合 brief 的排除范围。
