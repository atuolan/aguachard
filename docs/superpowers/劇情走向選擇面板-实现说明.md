# 劇情走向選擇面板 - 实现说明

## 概述

劇情走向選擇面板是一个交互式UI组件，当AI输出包含 `<intersection>`
标签的内容时，会在聊天界面中显示一个美观的选项面板，让用户可以选择五个不同的剧情走向之一。

## 架构设计

### 方案选择：纯正则 + 内联JavaScript

参考梁元·月食的实现模式，采用**完全基于正则替换**的方案，避免外部脚本依赖和YAML编码问题。

**关键优势：**

- ✅ 无需编译TypeScript脚本
- ✅ 避免YAML多行字符串编码错误
- ✅ 自包含，所有逻辑在HTML文件中
- ✅ 与酒馆助手的正则系统完美集成

## 技术实现

### 1. 正则配置

**位置：** `预设/木鳥也想飛/木鳥也想飛.yaml`

```yaml
正则:
  - 正则名称: 劇情走向選擇面板
    id: 00be914d-1525-4af0-83db-a0dc2f5121c8
    启用: true
    查找表达式: /<intersection>([\s\S]*?)<\/intersection>/gis
    文件: 正则\路线规划面板-HTML
    来源:
      用户输入: false
      AI输出: true
      思维链: false
    作用于:
      仅格式显示: true
      仅格式提示词: false
```

**工作流程：**

1. 正则匹配AI输出中的 `<intersection>...</intersection>` 标签
2. 捕获标签内的全部内容为 `$1`
3. 将整个标签替换为外部HTML文件的内容
4. HTML中的 `$1` 会被替换为捕获的原始内容

### 2. HTML面板结构

**位置：** `预设/木鳥也想飛/正则/路线规划面板-HTML.txt`

```html
<script class="intersection-raw-data" type="text/plain" style="display:none;">
  $1
</script>
<div class="intersection-options"></div>
```

- 隐藏的 `<script>` 标签存储原始fork内容（`$1`）
- 空的 `<div>` 容器等待JavaScript填充选项

### 3. 内联JavaScript解析

**核心逻辑：**

```javascript
var categories = [
  { name: '時間跳轉', regex: /fork[１1][:：]\s*(.*?)(?=(?:fork[２2]|$))/is, icon: '⏰' },
  { name: '場景發展', regex: /fork[２2][:：]\s*(.*?)(?=(?:fork[３3]|$))/is, icon: '🎬' },
  { name: 'NPC行動', regex: /fork[３3][:：]\s*(.*?)(?=(?:fork[４4]|$))/is, icon: '👤' },
  { name: '阻力形成', regex: /fork[４4][:：]\s*(.*?)(?=(?:fork[５5]|$))/is, icon: '⚠️' },
  { name: '機會形成', regex: /fork[５5][:：]\s*(.*?)(?=(?:$))/is, icon: '✨' },
];
```

**解析步骤：**

1. 获取隐藏元素中的原始文本
2. 使用正则表达式提取每个fork的内容
3. 动态创建DOM元素（选项卡片）
4. 绑定点击事件处理函数

### 4. 交互逻辑

```javascript
option.onclick = function () {
  if (typeof triggerSlash === 'function') {
    triggerSlash('/setinput ' + selectedText);
  } else {
    console.log('Selected:', selectedText);
  }
};
```

- 点击选项时调用 SillyTavern 的 `triggerSlash` API
- 使用 `/setinput` 命令将选中文本填入输入框
- 回退方案：如果API不可用，输出到控制台

## AI输出格式

AI需要输出以下格式的内容：

```
<intersection>
fork１：跳至何時，以及期間發生的關鍵變化。
fork２：當前場景可能發生的事件或局面變化。
fork３：NPC可能採取的行動或主動介入，但請注意合理性。
fork４：正在形成的限制、危險、衝突或代價。
fork５：正在形成的線索、資源、轉機或助力。
</intersection>
```

**条目配置：** `预设/木鳥也想飛/条目/【執行】53B｜五向劇情走向.txt`

## 故障排查

### 问题：面板不显示

**检查项：**

1. 正则是否启用（`启用: true`）
2. AI输出是否包含 `<intersection>` 标签
3. fork内容格式是否正确（fork１、fork２...）
4. 浏览器控制台是否有JavaScript错误

### 问题：点击无反应

**检查项：**

1. SillyTavern版本是否支持 `triggerSlash` API
2. 打开浏览器控制台查看日志输出
3. 检查 `/setinput` 命令是否可用

### 调试模式

在HTML的JavaScript部分添加日志：

```javascript
console.log('Raw text:', rawText);
console.log('Match result:', match);
console.log('Found count:', foundCount);
```
