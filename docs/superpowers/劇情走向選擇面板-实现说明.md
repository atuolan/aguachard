# 劇情走向選擇面板 - 实现说明

## 概述

劇情走向選擇面板是一个交互式UI组件，当AI输出包含 `<intersection>`
标签的内容时，会在聊天界面中显示一个美观的选项面板，让用户可以选择五个不同的剧情走向之一。

## 架构设计

### 方案选择：纯正则 + 内联JavaScript

参考梁元·月食的实现模式，采用**完全基于正则替换**的方案，避免外部脚本依赖和YAML编码问题。

**关键优势：**

- ✅ 无需编译TypeScript脚本
- ✅ 避免YAML多行字符串编码错误
- ✅ 自包含，所有逻辑在HTML文件中
- ✅ 与酒馆助手的正则系统完美集成
- ✅ 使用多个捕获组，无需JavaScript解析

## 技术实现

### 1. 正则配置

**位置：** `预设/木鳥也想飛/木鳥也想飛.yaml`

```yaml
正则:
  - 正则名称: 劇情走向選擇面板
    id: 00be914d-1525-4af0-83db-a0dc2f5121c8
    启用: true
    查找表达式: /<intersection>[\s\S]*?fork[１1][:：]\s*(.*?)[\s\S]*?fork[２2][:：]\s*(.*?)[\s\S]*?fork[３3][:：]\s*(.*?)[\s\S]*?fork[４4][:：]\s*(.*?)[\s\S]*?fork[５5][:：]\s*(.*?)[\s\S]*?<\/intersection>/gis
    文件: 正则\路线规划面板-HTML
    来源:
      用户输入: false
      AI输出: true
      思维链: false
    作用于:
      仅格式显示: true
      仅格式提示词: false
```

**工作流程：**

1. 正则匹配AI输出中的 `<intersection>...</intersection>` 标签
2. **分别捕获 5 个 fork 内容**为 `$1` 到 `$5`
3. 将整个标签替换为外部HTML文件的内容
4. HTML中的 `$1-$5` 会被替换为对应的 fork 内容

**捕获组说明：**

- `$1`: fork１的内容（時間跳轉）
- `$2`: fork２的内容（場景發展）
- `$3`: fork３的内容（NPC行動）
- `$4`: fork４的内容（阻力形成）
- `$5`: fork５的内容（機會形成）

### 2. HTML面板结构

**位置：** `预设/木鳥也想飛/正则/路线规划面板-HTML.txt`

```html
<div class="intersection-option" data-text="$1">
  <div class="intersection-option-content">
    <div class="intersection-option-category">⏰ 【時間跳轉】</div>
    <div class="intersection-option-text">$1</div>
  </div>
</div>
<!-- $2-$5 同样的结构 -->
```

**优势：**

- 每个选项直接使用捕获组 `$1-$5`
- 不需要隐藏元素存储原始内容
- 不需要 JavaScript 解析 fork 内容
- 代码更简洁，性能更好

### 3. 交互逻辑

```javascript
var options = wrapper.querySelectorAll('.intersection-option');

options.forEach(function (option) {
  var text = option.getAttribute('data-text');
  if (text) {
    option.onclick = function () {
      if (typeof triggerSlash === 'function') {
        triggerSlash('/setinput ' + text);
      } else {
        console.log('Selected:', text);
      }
    };
  }
});
```

- 读取 `data-text` 属性（已被替换为实际 fork 内容）
- 点击选项时调用 SillyTavern 的 `triggerSlash` API
- 使用 `/setinput` 命令将选中文本填入输入框
- 回退方案：如果API不可用，输出到控制台

## AI输出格式

AI需要输出以下格式的内容：

```
<intersection>
fork１：跳至何時，以及期間發生的關鍵變化。
fork２：當前場景可能發生的事件或局面變化。
fork３：NPC可能採取的行動或主動介入，但請注意合理性。
fork４：正在形成的限制、危險、衝突或代價。
fork５：正在形成的線索、資源、轉機或助力。
</intersection>
```

**条目配置：** `预设/木鳥也想飛/条目/【執行】53B｜五向劇情走向.txt`

## 实现演进

### 方案对比

| 维度     | TypeScript 方案  | 单捕获组方案     | 多捕获组方案 ✅ |
| -------- | ---------------- | ---------------- | --------------- |
| 依赖     | 需要webpack编译  | 无编译依赖       | 无编译依赖      |
| YAML配置 | 多行HTML编码困难 | 引用外部文件     | 引用外部文件    |
| 捕获方式 | N/A              | 捕获全部内容     | 分别捕获5个fork |
| JS解析   | 需要             | 需要复杂正则解析 | 不需要          |
| 代码量   | 170行TS          | 222行            | 197行           |
| 可维护性 | 需要构建         | 中等             | 最佳            |

### 优化历程

1. **v1**: TypeScript脚本方案 - 遇到YAML编码问题
2. **v2**: 纯正则+单捕获组 - 需要JavaScript解析fork
3. **v3**: 纯正则+多捕获组 - 最简洁高效 ✅

## 故障排查

### 问题：面板不显示

**检查项：**

1. 正则是否启用（`启用: true`）
2. AI输出是否包含 `<intersection>` 标签
3. fork内容格式是否正确（fork１、fork２... 用全角数字）
4. 浏览器控制台是否有JavaScript错误

### 问题：点击无反应

**检查项：**

1. SillyTavern版本是否支持 `triggerSlash` API
2. 打开浏览器控制台查看日志输出
3. 检查 `/setinput` 命令是否可用

### 调试模式

在HTML的JavaScript部分添加日志：

```javascript
options.forEach(function (option) {
  var text = option.getAttribute('data-text');
  console.log('Option text:', text);
  // ...
});
```
