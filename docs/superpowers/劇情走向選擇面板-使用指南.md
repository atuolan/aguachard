# 劇情走向選擇面板 - 快速使用指南

## 功能说明

当 AI 输出包含 `<intersection>` 标签的劇情分支时，会自动显示一个交互式选择面板，包含五个不同方向的选项。

## 使用步骤

### 1. 启用条目

在预设中启用以下条目：

```
【執行】53B｜五向劇情走向
```

### 2. 触发面板

AI 会在适当时机输出如下格式：

```
<intersection>
fork１：跳至何時，以及期間發生的關鍵變化。
fork２：當前場景可能發生的事件或局面變化。
fork３：NPC可能採取的行動或主動介入，但請注意合理性。
fork４：正在形成的限制、危險、衝突或代價。
fork５：正在形成的線索、資源、轉機或助力。
</intersection>
```

### 3. 选择选项

- 面板会自动显示五个劇情方向
- 点击任意选项
- 所选内容会自动填入输入框
- 可以继续编辑或直接发送

## 五个分支类型

| 图标 | 类别     | 说明                     |
| ---- | -------- | ------------------------ |
| ⏰   | 時間跳轉 | 时间线变化和期间关键事件 |
| 🎬   | 場景發展 | 当前场景可能发生的变化   |
| 👤   | NPC行動  | 角色主动介入和行动       |
| ⚠️   | 阻力形成 | 正在形成的困难和冲突     |
| ✨   | 機會形成 | 正在形成的机遇和转机     |

## 工作原理

1. **正则捕获**：`<intersection>` 标签及其内容被正则表达式捕获
2. **面板替换**：标签被替换为 HTML 面板
3. **内容解析**：JavaScript 解析 fork1-5 的内容
4. **动态生成**：创建可点击的选项卡片
5. **填入输入框**：点击选项后使用 `/setinput` 命令填入

## 技术架构

- **实现方式**：纯正则 + 内联 JavaScript
- **无需编译**：不依赖外部脚本
- **自包含**：所有逻辑在 HTML 文件中
- **参考实现**：梁元·月食面板模式
