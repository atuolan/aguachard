# 卓云和 MVU 現代化升級計畫

## 階段一：更新腳本配置與加強 UI 顯示 (正則替換)
**目標**：讓 MVU 腳本使用更穩定的版本，並在前端酒館的對話介面中，把「跳代碼」的過程變成優雅的「正在讀取 / 變數折疊區塊」。

1.  **更新腳本 URL**：修改 `卓云和.yaml`，去掉 `bundle.js` 前的 `@master`，確保長期的穩定性。
2.  **開放除錯按鈕**：將 `清除旧楼层变量` 設為 `可见: true`。
3.  **替換正則表達式**：
    *   移除舊的 `去除变量更新` 正則。
    *   新增 `[不发送]去除变量更新`：避免已生成的變數代碼再次發送給 AI。
    *   新增 `[折叠]变量更新中`：處理打字機過程中的跳代碼顯示問題。
    *   新增 `[折叠]完整变量更新`：將完成的 JSON Patch 隱藏在 `<details>` 裡，隨點隨看。

---

## 階段二：建構結構化變數 (Zod Schema) 與世界書拆分
**目標**：根治 AI 計算不準、常常忘記扣好感/加戒備的問題，從純文本提示轉向程式等級的強力約朿。

1.  **盤點現有變數**：根據目前的 `状态栏` 和 `数值规则`，抽出 `好感度`、`戒备值`、`爱意值` 以及其它可能需要的字串變數。
2.  **創建 `变量结构.js`**：
    *   使用 `zod` 定義變數的資料型態、預設值（例如 `好感度` 最大 100，最低 0）。
    *   利用 `registerMvuSchema(Schema)` 註冊進系統。
3.  **拆解並建立新的世界書 (World Info)**：
    *   **建立 `变量\变量列表.txt`**：用來即時抓取並將當前變數傳給 AI。
    *   **建立 `变量\变量输出格式.yaml`**：規範 AI 使用 JSON Patch，確保吐出來的每一個數值系統都能解析。
    *   **建立 `变量\变量更新规则.yaml`**：將原本的 `数值规则` 文字濃縮，直接指導 AI 什麼時候做增減（Delta）或替換（Replace）。
4.  **連結世界書與腳本**：
    *   將這幾個新的世界書項目和 `变量结构.js` 配置寫進 `卓云和.yaml` 的「条目」與「脚本库」中。
    *   關閉舊的 `数值规则` 以免衝突。

---

## 階段三：測試與優化
1.  執行 `node tavern_sync.mjs bundle 卓雲和` 來打包查看是否報錯（如果環境支援的話，不然就直接在酒館內匯入查看）。
2.  討論與微調 `变量更新规则.yaml` 的提示詞，讓 AI 寫出的心理活動與變數變化更精準。
