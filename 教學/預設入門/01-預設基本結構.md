# 第 1 課：預設基本結構

這一課只學一件事：

**看懂一個最小的預設檔到底長什麼樣。**

請先不要管大型預設裡那些很長的內容。
先看最簡單版本。

---

## 1. 最小範例

下面這段就是一個很小的預設範例：

```yaml
设置:
  上下文长度: 32000
  最大回复token数: 2000
  温度: 1

锚点: {}

提示词:
  - 名称: 基本身份
    启用: true
    插入位置:
      类型: 相对
    角色: 系统
    内容: 你是一位溫柔、簡潔、願意配合故事演出的角色。

  - 名称: 输出要求
    启用: true
    插入位置:
      类型: 相对
    角色: 系统
    内容: 請使用繁體中文回答，並保持自然對話感。
```

---

## 2. 一行一行理解

### [`设置`](教學/預設入門/01-預設基本結構.md)
這裡通常是模型參數。
例如：

- `上下文长度`：一次能帶多少歷史內容
- `最大回复token数`：單次最大輸出長度
- `温度`：創意程度

你可以先把它想成：
**這是模型的運轉參數，不是角色內容本身。**

### [`锚点`](教學/預設入門/01-預設基本結構.md)
這裡通常用來放一些插入定位設定。
初學時你可以先把它當成「進階功能區」，先略過沒關係。

### [`提示词`](教學/預設入門/01-預設基本結構.md)
這裡最重要。

你可以把它理解成：
**要送給 AI 的規則清單。**

每一個 `- 名称:` 開頭的區塊，就是一個模組、一條規則、或一段提示詞。

---

## 3. 單一提示詞模組怎麼看

例如這段：

```yaml
  - 名称: 基本身份
    启用: true
    插入位置:
      类型: 相对
    角色: 系统
    内容: 你是一位溫柔、簡潔、願意配合故事演出的角色。
```

你可以這樣理解：

- `名称`：這條規則叫什麼名字，方便你自己辨認
- `启用: true`：這條規則有開啟
- `插入位置`：這條規則要放到提示詞的哪個位置
- `角色: 系统`：這段會以 system/system prompt 的身份送給 AI
- `内容`：真正送出去的文字

所以這段的白話意思就是：

**「把『你是一位溫柔、簡潔、願意配合故事演出的角色』這句系統提示，送給 AI。」**

---

## 4. [`启用: true`](教學/預設入門/01-預設基本結構.md) 與 [`启用: false`](教學/預設入門/01-預設基本結構.md)

這是你最先要熟的東西。

### 開啟時
```yaml
启用: true
```
意思是：
**這條規則會生效。**

### 關閉時
```yaml
启用: false
```
意思是：
**這條規則暫時不送給 AI。**

所以大型預設本質上很像一個開關面板。
你看到一大堆模組，其實就是：

- 這個要不要開
- 那個要不要開
- 哪幾個一起開
- 哪幾個不能同時開

---

## 5. [`内容`](教學/預設入門/01-預設基本結構.md) 跟 [`文件`](教學/預設入門/01-預設基本結構.md) 的差別

你會看到有些模組直接寫：

```yaml
内容: 請使用繁體中文回答。
```

也有些會寫：

```yaml
文件: 条目\某個模組名稱
```

差別是：

### 直接寫 [`内容`](教學/預設入門/01-預設基本結構.md)
適合短文字。

### 用 [`文件`](教學/預設入門/01-預設基本結構.md)
適合長提示詞。
作者會把內容拆去別的檔案，主檔只保留引用。

這也是為什麼像 [`預設/Karu/V3.4.4_GAL_you_4-5-op-think(私有)_KaruKaru_noass.yaml`](預設/Karu/V3.4.4_GAL_you_4-5-op-think(私有)_KaruKaru_noass.yaml) 那種大型預設，看起來像總控台。
因為真正的大段文字常常被拆到別處了。

---

## 6. 最小可抄範例

如果你想自己做一個超簡單預設，可以先從這個開始：

```yaml
设置:
  上下文长度: 32000
  最大回复token数: 2000
  温度: 1

锚点: {}

提示词:
  - 名称: 角色身份
    启用: true
    插入位置:
      类型: 相对
    角色: 系统
    内容: 你是一名會陪我進行角色扮演的角色。

  - 名称: 回复格式
    启用: true
    插入位置:
      类型: 相对
    角色: 系统
    内容: 請使用繁體中文，自然回應，不要跳出角色。
```

這就是預設最核心的骨架。

---

## 7. 你現在先記住這一句話

**預設 = 模型參數 + 一串可開關的提示詞模組。**

只要你能看懂：

- 哪裡是設定
- 哪裡是提示詞
- 哪條規則有開
- 哪條規則有關

你就已經超過完全新手了。

---

## 8. 小練習

請自己試著讀下面這段：

```yaml
- 名称: 限制输出长度
  启用: false
  插入位置:
    类型: 相对
  角色: 系统
  内容: 請簡短回答，控制在兩段內。
```

你要能自己說出來：

1. 這條規則名字是什麼？
2. 它現在有沒有生效？
3. 它如果打開，會要求 AI 做什麼？

如果你能回答出來，就代表這一課你已經會了。
