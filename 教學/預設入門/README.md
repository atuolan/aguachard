## 這套教學想教你的事

你不需要一開始就學會大型預設。
你只要先學會下面四件事：

- 預設最基本的 YAML 長什麼樣
- `启用: true/false` 到底在控制什麼
- [`{{setvar::...}}`](教學/預設入門/02-變數與注入.md) 和 [`{{getvar::...}}`](教學/預設入門/02-變數與注入.md) 在做什麼
- 為什麼有些預設會寫「防道歉」、「預先道歉」、「破甲」這種東西

## 你應該怎麼讀

每一課都會有三個區塊：

1. 概念解釋
2. 最小可讀範例
3. 你可以自己改的練習

## 最重要的觀念

大型預設不是魔法。
它只是把很多小技巧組在一起：

- 一些系統提示詞
- 一些變數
- 一些輸出格式要求
- 一些針對模型行為的修正
- 一些用來開關功能的模組

當你把小技巧一個一個看懂之後，大型預設就只是「很多小積木拼在一起」。
