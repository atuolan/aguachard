# 第 2 課：變數與注入

這一課只學兩個指令：

- `{{setvar::變數名::內容}}`
- `{{getvar::變數名}}`

如果你把這兩個學會，大型預設就會突然好懂很多。

---

## 1. 先用一句人話理解

- [`setvar`](教學/預設入門/02-變數與注入.md) = 先把一段文字放進一個有名字的盒子裡
- [`getvar`](教學/預設入門/02-變數與注入.md) = 需要用的時候，再把盒子裡的東西拿出來

所以它其實就是：

**先存起來，之後再插進去。**

這就是「注入」最簡單的意思。

---

## 2. 最小範例

```yaml
提示词:
  - 名称: 存入格式要求
    启用: true
    插入位置:
      类型: 相对
    角色: 系统
    内容: "{{setvar::格式要求::請使用繁體中文，並保持口語自然。}}"

  - 名称: 真正注入格式要求
    启用: true
    插入位置:
      类型: 相对
    角色: 系统
    内容: "回覆規則：{{getvar::格式要求}}"
```

---

## 3. 這段實際上發生了什麼

第一段：

```yaml
{{setvar::格式要求::請使用繁體中文，並保持口語自然。}}
```

意思是：

> 建立一個叫做「格式要求」的變數，裡面放進這段文字：
> 「請使用繁體中文，並保持口語自然。」

第二段：

```yaml
回覆規則：{{getvar::格式要求}}
```

意思是：

> 在這個位置，把「格式要求」變數裡面的內容拿出來。

所以最後送給 AI 的實際文字，會接近：

```text
回覆規則：請使用繁體中文，並保持口語自然。
```

---

## 4. 為什麼不直接寫死？

你可能會想：

```yaml
內容: 回覆規則：請使用繁體中文，並保持口語自然。
```

直接這樣不是更簡單嗎？

對，小預設常常可以直接寫。
但大型預設不用直接寫，是因為它需要：

- 先在上面收集很多規則
- 最後再統一插入某個位置
- 有些規則要能開關
- 有些規則要互相組合

所以變數的價值在於：

**把零散規則集中管理。**

---

## 5. 再看一個比較像大型預設的例子

```yaml
提示词:
  - 名称: 防重複規則
    启用: true
    插入位置:
      类型: 相对
    角色: 系统
    内容: "{{setvar::防重複::不要重複上一輪的句型與結尾。}}"

  - 名称: 角色語氣
    启用: true
    插入位置:
      类型: 相对
    角色: 系统
    内容: "{{setvar::角色語氣::請保持溫柔、克制、成熟的說話方式。}}"

  - 名称: 最終輸出控制
    启用: true
    插入位置:
      类型: 相对
    角色: 系统
    内容: |
      請遵守以下要求：
      1. {{getvar::防重複}}
      2. {{getvar::角色語氣}}
```

最後注入後，AI 看到的東西會近似：

```text
請遵守以下要求：
1. 不要重複上一輪的句型與結尾。
2. 請保持溫柔、克制、成熟的說話方式。
```

這樣是不是就很像「組裝」了？

---

## 6. 為什麼大型預設很愛這樣寫

像 [`預設/Karu/V3.4.4_GAL_you_4-5-op-think(私有)_KaruKaru_noass.yaml`](預設/Karu/V3.4.4_GAL_you_4-5-op-think(私有)_KaruKaru_noass.yaml) 這種大預設，常常不是把每條規則都直接寫在同一個地方。

它比較像這樣：

1. 前面先定義很多小零件
2. 中間根據開關決定哪些零件存在
3. 最後在輸出框架裡把零件全部裝上去

所以你看到大量的 [`{{setvar::...}}`](教學/預設入門/02-變數與注入.md) 時，不要怕。
你只要問自己兩件事：

1. 它把什麼內容存起來？
2. 這個內容之後會在哪裡被拿出來？

只要這兩題答得出來，基本上就看懂了。

---

## 7. 初學者最常卡住的點

### 卡點 1：以為 [`setvar`](教學/預設入門/02-變數與注入.md) 會直接顯示給 AI
不一定。
它常常只是先存起來。
真正關鍵的是後面有沒有 [`getvar`](教學/預設入門/02-變數與注入.md) 把它拿出來。

### 卡點 2：看不出變數在哪裡用
這很正常。
大型預設很長，所以你需要習慣：

- 先找 `setvar`
- 再找同名的 `getvar`

### 卡點 3：以為變數一定只能放一句話
不是。
變數裡可以放：

- 一句規則
- 一整段說明
- 一個 XML 標籤片段
- 一組輸出格式
- 一段思考框架

---

## 8. 最小可抄範例

你可以自己試做一個超小版本：

```yaml
设置:
  上下文长度: 32000
  最大回复token数: 2000
  温度: 1

锚点: {}

提示词:
  - 名称: 存入身份
    启用: true
    插入位置:
      类型: 相对
    角色: 系统
    内容: "{{setvar::身份::你是一位安靜、溫柔的姐姐。}}"

  - 名称: 存入格式
    启用: true
    插入位置:
      类型: 相对
    角色: 系统
    内容: "{{setvar::格式::請使用繁體中文回答，每次不超過三段。}}"

  - 名称: 最終提示
    启用: true
    插入位置:
      类型: 相对
    角色: 系统
    内容: |
      {{getvar::身份}}
      {{getvar::格式}}
```

這就是最簡單的「先存、後取、再組裝」。

## 9. 小練習

請試著自己解讀這段：

```yaml
- 名称: 存入防搶話
  启用: true
  插入位置:
    类型: 相对
  角色: 系统
  内容: "{{setvar::防搶話::不要替使用者決定下一句話。}}"

- 名称: 最後規則
  启用: true
  插入位置:
    类型: 相对
  角色: 系统
  内容: "{{getvar::防搶話}}"
```

你應該要能自己說出：

1. 存進去的規則是什麼？
2. 最後 AI 會實際看到什麼？
3. 這種寫法比直接寫死更適合哪種情況？

如果這三題你能答出來，你就已經進到大型預設的核心地帶了。
